# WebErstes

Ein Visual-Studio-Projekt zur Einführung in die Entwicklung von Webanwendungen.

## Beschreibung

Das Projekt **WebErstes** dient als Einstieg in die Webentwicklung mit Visual Studio. Im Mittelpunkt stehen die grundlegende Struktur einer Webanwendung, die Erstellung von Webseiten und die Darstellung von Inhalten im Webbrowser.

## Funktionen

- Erstellung einer einfachen Webanwendung
- Darstellung von Webseiten im Browser
- Grundlagen der webbasierten Benutzeroberfläche
- Einführung in die Struktur eines Webprojekts
- Lokale Ausführung und Testen der Anwendung

## Technologien

- Microsoft Visual Studio
- Webtechnologien
- Visual-Studio-Projektmappe (.sln)

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WebErstes.git
   ```

2. Die Datei `WebErstes.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
5. Die Webseite im Browser öffnen, sofern sie nicht automatisch gestartet wird.
